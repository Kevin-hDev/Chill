Bien, le skill frontend-design me pousse à pousser le design plus loin. Avant
   de coder, voici ma réflexion :

  ---
  Direction artistique : "Terminal Luxury"

  Concept : La sophistication de Linear rencontre l'authenticité brute d'un
  terminal. Sombre, minimal, mais avec des moments de chaleur inattendue — le
  halo vert, les animations flottantes. Un terminal haut de gamme qu'on a envie
   d'utiliser.

  Ce qui rendra le site mémorable : L'esthétique terminal qui s'infiltre dans
  le design lui-même, pas juste dans les blocs de code.

  Un point important sur la typographie : Le skill frontend-design me
  déconseille fortement d'utiliser Inter — c'est la police la plus utilisée par
   les sites "faits par IA" en 2026, ça fait générique. Pour un site qui
  s'appelle "Chill" et qui présente un terminal, voici ce que je propose :
  Élément: Titres/H1/H2
  Avant (plan): Inter Variable
  Proposition: JetBrains Mono (monospace = on-brand terminal, distinctif,
    personne ne fait ça)
  ────────────────────────────────────────
  Élément: Body/UI
  Avant (plan): Inter Variable
  Proposition: Plus Jakarta Sans (moderne, lisible, plus de caractère qu'Inter)
  ────────────────────────────────────────
  Élément: Code
  Avant (plan): JetBrains Mono
  Proposition: JetBrains Mono (inchangé)
  L'idée : "Chill" en JetBrains Mono dans le hero, ça colle parfaitement avec
  l'identité terminal. Et Plus Jakarta Sans pour le body, c'est propre et
  lisible sans être générique.

  Autres détails design :
  - Fond avec une subtile texture noise/grain (pas un aplat plat)
  - Le halo vert derrière le logo avec un mesh gradient, pas un simple radial
  - Bordures avec un léger glow vert sur hover (identité accent)
  - Cards avec un effet de profondeur subtil (micro-shadow + border-glow)

  Tu valides ces changements de fonts et ces ajouts de détails, ou tu préfères
  rester sur Inter ?
